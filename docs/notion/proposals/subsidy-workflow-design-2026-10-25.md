# 青壯額度管理｜同頁作業設計提案

2026-10-25。狀態：設計提案，尚未套用Notion；本回合沒有修改任何Notion頁面、檢視、公式或業務資料。

## 1. 設計結論

保留既有導覽和使用者熟悉的表格操作，將同類工作排在同一頁。日常打開頁面，直接看到「治療所本期額度、個案使用與待處理、心理師本週額度」。在同一列看見判斷依據及下一個動作；不要求進資料庫才能查餘額，不增加年度參與表填寫前置。

低頻核定、週回報、方案規則、歷史放在相應主表下方的同頁收合區，不拆成另一個日常入口。收合是閱讀安排，不能宣稱關閉後就不載入。頁面只放資料與短提示，設計理由與驗收紀錄留在GitHub。

目前定位：已復原的「補助方案管理｜TEST」含7個檢視區塊；另一個「額度與警示工作台」仍含前輪改版殘留的8區。兩者有相同來源與不同檢視，不能再同時作兩個主入口。後續應以已復原頁作單一改版對象，保留其頁面ID及導覽，另一頁待功能覆蓋及依賴核對後才退役。本次未退役任何頁。

## 3. 同頁資訊架構

保留原左側導覽，不改首頁。右側按下列順序排列，桌面以直向區塊為主，避免窄欄塞進寬表。

### A. 治療所本期額度：短表直接看

每列一個方案核定期。顯示「方案期別、核定次數、已完成、已預約、可再安排、狀態」。目前僅青壯時就是一列，不做大型數字卡，也不另外建統計表。

核定總數從原調整紀錄彙總。追加、減額、期中停用等原因在同頁下方的「核定與增減」查看。額度單位明示次數；補助金額與請款金額分開，不讓1,600元和一次額度混在同欄。

多個有效期並行時顯示多列，不把上一期未結作業靜默藏掉。

### B. 個案使用與待處理：主要作業表

預設直接顯示該方案仍待辦理的個案，不必先切分頁。一般寬度優先顯示以下欄位：

1. 個案／歷程：沿用目前辨識方式，勿新增個資複本。
2. 下一步：短句，例如「核對他處次數」「安排末次」「補結案文件」「核對超額」。
3. 已完成／已預約：兩欄並列，不能合併成看不懂的占用。
4. 他處使用：顯示「未確認」或「已確認0次」等明確文字。
5. 可再安排：數字或「待核對」，未知不能當0。
6. 下次會談／使用截止：空白不得誤當未預約或無期限。

主責心理師及方案期別在需要跨心理師或跨期查看時顯示；同一固定期別的窄表可用明確區標代替重複欄。完整核對日期、說明、會談關聯保留在原資料，不全部攤開。必要時以Notion側邊預覽補細節，日常主要答案仍在表中。

「進行中」只描述臨床歷程；「額度已滿」只描述額度；「待核對」只描述資訊完整性。三者不能混成一個結案狀態。逾期但尚未結案、已預約占滿但仍要完成會談、需補末次文件的人都要保留可見。

補充分頁只處理主表之外的查閱：全部／已結束／資料核對詳情。不以切分頁作為發現重要異常的唯一方法，不同條件再堆成多張相同個案表。

### C. 心理師本週額度：同頁排班依據

每列一位實際參與本方案的心理師。顯示「心理師、本所已完成、本所已預約、他處使用、可再安排、核對狀態」，區標明確寫當週起迄。沒有週回報的人也必須顯示為「未回報」，不可因沒有週紀錄而整個消失。

「他處使用回報」在緊接主表的同頁區域，回報者不用另外找設定頁。可用既有回報表的本週檢視，少量紀錄直接顯示；若大多使用者只看而非填，保留同頁收合。是否收合以實際頻率決定，不作效能承諾。

目前Staff的青壯本週欄位與部分個案欄位仍有115專用邏輯。新年度尚未驗證前必須顯示「未設定／待驗證」，不能換個標題就當成116可用。

### D. 同頁維護與歷史

「核定與增減」緊鄰院所區；「他處週回報」緊鄰心理師區。頁尾僅收合方案規則與舊期歷史，不以長篇操作說明佔首屏。保留既有參與與對照紀錄，避免把歷史表重新升格成青壯必填工作。

## 4. 數字與異常語言

已用次數＝本所本期已完成＋同一期已確認他處使用。

可再安排＝本期核定個案上限－已用次數－本所有效預約。此為排約容量，不等於政府已核銷；他處未確認時顯示待核對，不計出可放行數。

若他處回報包含未來預約，必須將已完成及預約分開，不能把同一數字同時加進兩處。取消、改期、no-show是否占用依當期規則分類；未確認的服務狀態列異常。

| 條件 | 畫面文字 | 下一步 |
|---|---|---|
| 資料不足 | 待核對：他處次數未確認 | 核對後填原確認欄 |
| 已完成＋他處使用達上限 | 已用完 | 處理結案或後續自費，不再補助排約 |
| 尚未全部完成，但有效預約已占滿 | 已預約滿 | 完成現有預約；不等同已用完 |
| 剩一次尚可安排 | 可安排末次 | 核對日期與末次文件 |
| 加總超上限 | 超額待查 | 查看會談明細，保留負值供查錯 |
| 期限屆滿仍進行中 | 逾期待處理 | 依原人工行政流程處理，不自動結案 |
| 設定缺漏／未知年度 | 規則未確認 | 由維護者核實，不沿用上一期數字 |

「最後一次已預約」必須同時證實本期已完成、他處用量、有效預約及下次服務歸屬，不能只憑剩餘0命名。規則可以只輸出一個下一步，但核對詳情保留全部原因，避免優先序掩蓋第二個問題。

## 5. 跨年度、跨方案維護

### 方案實例是計算邊界

沿用Price Plans，一筆代表一個具體核定期，例如青壯115；下一期另建方案實例。核定期可跨自然年度，一個年度也可有不同期別，實際依主管機關核定。所有會談、週回報、調整紀錄都必須歸屬確切方案ID。不能只用名稱含青壯或年份篩選。

設定項至少區分：補助對象、起迄、個案上限、心理師週限與切週方式、首次服務期限、相鄰間隔、費用、例外處理、官方／地方契約依據、版本與生效日期。已有結構欄位優先沿用；只有真正參與計算者才新增型別欄，細節仍存規則正文。空值、零、無上限、不適用分開表達。

同年度中途規則變更不能改一個上限就回溯改寫過去結果。先確認適用服務日及主管核定版本；必要時建立新方案版本或有效期設定，再做受影響紀錄比對。

### 不逐年複製欄位與資料庫

每年新增方案紀錄與對應檢視設定，不新增Cases「青壯116…」或Staff「青壯117…」欄。新年度不覆寫舊資料，也不複製個案主檔。舊專年欄位先保留，直到找到完整公式依賴與替代值逐筆驗證，不能以維護方便直接刪除。

青壯目前使用者已確認的單一歷程操作保留。通用的個案×方案參與紀錄可承接不同方案的期別屬性，但不得再要求青壯行政人員為同一件事重填。若未來必須依此做跨歷程彙總，必須先具備可靠同步與唯一性檢查，並取得新的業務決策；不在此次版面改善中偷換資料來源。

心理師長期週額度以「心理師×方案實例×該期定義的週起日」為單位，沿用既有週紀錄。若改以週紀錄作主表，須先確保每位參與心理師都能出現；不可增加每週手建空白紀錄的行政負擔。未完成涵蓋機制前，保留現行完整Staff名單作顯示基礎。

### Notion原生範圍限制

普通Notion頁面上，多個獨立資料庫不會因上方一個年度下拉就自動同步篩選。設計不放一個假的全頁年度選擇器。第一階段各區明確標示期別，維護者一次校準三區；多期並行則按方案顯示分組或加期別欄。若使用Notion新式dashboard全域篩選，需另核對方案支援、帳戶權限及關聯欄位，不能預設免費版可用。

新年度啟用程序：建立方案與依據→核定額度→核實當期規則及公式支援→複用原有檢視並指向新方案→三層範圍及年界測試→新期上線、舊期改歷史查閱。只改篩選並不代表115專用公式已通用化。

## 6. 效能：保留直接查閱的前提下改善

預設三個日常區。保留主資料表，先減少同來源重複展開、非必要顯示欄位，以及無界限的全歷史查詢；不把資料替換成需進資料庫的連結，也不刪法定歷史或未完成工作。

優先以原生方案關聯、服務狀態及必要日期縮小資料範圍；臨床狀態篩選不能排掉逾期待處理或預約待完成。重公式／Rollup仍必要時顯示，但先避免依它們重複排序篩選。現有開案日不等於首次補助服務日，不能為了速度混用。

資料庫列數初始載入設定若可用，依實際數量測試；需要按載入更多會影響查閱，不預設十列最適合。收合區是否實際減少查詢不能由畫面推定。

性能測試採同一裝置、同一帳戶、相近網路，各三次首次開頁及再次開頁，記錄從開啟到三個主區可讀、可點的時間，取中位數；另測搜尋與編輯回應。只有速度改善且關鍵資訊未變成額外跳頁才算通過，不能以inline數減少宣稱成功。

## 7. 實作分界與風險

第一步：在可回復的隔離副本驗證欄位投影、區塊對應、版面順序；不在現用頁反覆試排。

第二步：確認來源與範圍後，以原頁ID作小幅編排；逐塊移動後立即Fetch，確保標題下的collection ID正確。備份中的url加data-source-url重新貼回可能新建預設檢視，須比對完整View設定，不能把7張表存在等同復原成功。

第三步：只有需要「可再安排／下一步／使用截止」且原公式無法提供時才修改公式。此時須先取得完整expression與依賴閉包，備份與隔離測試；目前連接器僅給公式參照，不能假裝已能安全改寫。

其他必要查核：核對其他前台／GAS是否依賴頁面、view或property IDs。畫面精簡不改外部契約。View篩選不是權限隔離；資料表不額外展示身分證、完整生日、地址、病歷或薪資。

不適合用拖曳修改額度或資格的看板，避免不慎變更；主表保留原Table、原紀錄及側邊預覽。

## 8. 驗收條件

| 題目 | 操作 | 通過條件 |
|---|---|---|
| 日常可讀 | 打開頁面 | 不需開其他資料庫就看到院所、個案、心理師資料 |
| 排約情境 | 查一位熟悉個案及心理師 | 可判讀兩者剩餘、他處確認及期限；未知不顯示可安排 |
| 用完與預約滿 | 分別查兩種已知紀錄 | 文案及下一步不同，不用猜公式含義 |
| 更新一次 | 隔離測試會談完成／取消／改期 | 原會談更新後數字合理，不重填額度總數 |
| 低頻操作 | 核對週回報與核定增加 | 在相鄰同頁完成，來源與期別正確 |
| 邊界 | 測第7天、跨月、逾期、超額、未回報、跨週 | 依適用版本正確提示，保留例外與人工處理 |
| 多期 | 同個案不同方案／年度各一筆 | 分開計數；未知新年度不自動沿用115 |
| 名單完整 | 有回報與無回報心理師各一位 | 均可見，未回報有明確提示 |
| 權限 | 用實際工作者帳戶 | 可做既有工作，沒有額外暴露敏感欄位 |
| 效能 | 前後同條件各三次 | 開頁及操作有實測改善，沒有以跳頁換速度 |

最後回復測試包含原page、linked block、saved views、原公式與資料內容；新建linked block會改ID，不能假稱原ID保留。
