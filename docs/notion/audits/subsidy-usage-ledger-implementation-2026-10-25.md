## 最小資料模型
- 用量一筆 = Cases 個案 ID + Price Plan 實例 ID。不同年度、方案或獨立額度期別各新增一筆紀錄，不複製資料庫或增加方案專用欄位。
- 用量共 13 個屬性：名稱、個案、補助方案、他處回報次數、他處使用已確認、他處確認日期、使用截止日、個案上限、本所已完成、本所已預約、剩餘次數、額度提示、日期提示。
- Cases 以既有「關聯會談」取得 Sessions；公式按每筆 Session 的實際主收費方案 ID 篩選，完成／預約各計一次，取消／改期／no-show 不計入。沒有新增每次會談必填的用量關聯。
- Cases 增加反向「補助方案用量」關聯；服務歷程透過個案及自身「💲收費方案」比對用量紀錄。查無或重複時明確警示，不擅取第一筆當正確值。
- 新建過的歷程分類輔助 Rollup 及用量→歷程關聯已移除。服務歷程沒有新增方案用量輸入欄；原兩個額度公式已改接。
- 日常直接顯示個案關聯，無須重複輸入顯示名稱。「回報／期限核對」tab 可直接編輯他處回報及日期。
- 心理師新增查閱方案、免週回報方案、通用本週摘要；Price Plans 增加每週起始日及通用方案類型判斷。週上限與週起算日取自所選期別，不靠空白週報提供上限。
- 他處採單一回報數字，不再拆完成／預約。未確認或空白不能視為已確認零；只在本所接案者須有對應方案及完整週期涵蓋的有效確認，才免填零週報。
